# Parcl | Real Estate Buyer Intelligence

An interactive Streamlit business intelligence dashboard
demonstrating real estate buyer segmentation, investment
analytics, and geographic performance analysis.

## Public Demonstration

This repository uses independently generated fictional
buyer and property data.

The segment labels are simulated for demonstration
purposes and are not predictions from a trained model.

The original internship datasets and model evaluation
results are not included.

## Dashboard Modules

- Executive Overview
- Buyer Segmentation
- Investment Intelligence
- Geographic Analytics
- Segmentation Methodology

## Technology

Python, Pandas, NumPy, Plotly, Streamlit

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data Disclaimer

All records in this public demonstration are synthetic.
Financial metrics are derived from fictional transactions
and must not be interpreted as real market results.
